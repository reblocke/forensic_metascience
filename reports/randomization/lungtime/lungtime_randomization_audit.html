2 Load Inputs

repo_root <- normalizePath("..", winslash = "/", mustWork = TRUE)
input_dir <- file.path(repo_root, "reports", "randomization", "lungtime")

required_files <- c(
  "row_level_results.csv",
  "pooled_pvalues.csv",
  "simdistr_variable_pvalues.csv",
  "simdistr_combined_pvalues.csv"
)
missing_files <- required_files[!file.exists(file.path(input_dir, required_files))]
if (length(missing_files) > 0) {
  stop(
    "Missing expected analysis outputs: ",
    paste(missing_files, collapse = ", "),
    ". Run scripts/run_randomization_forensics.R first."
  )
}

8 Interpretation Notes

  • This is a baseline-balance forensic screen, not a causal efficacy analysis.
  • Row-level p-values depend on one-vs-rest encodings for multi-level variables.
  • Reported manuscript p-values may use test choices that differ from recalculation methods.
  • Joint p-value methods are sensitive to correlation among baseline variables.
